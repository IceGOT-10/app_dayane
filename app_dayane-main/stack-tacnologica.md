# Stack Tecnológica do Aplicativo

## Base do Projeto
- Framework: React Native com Expo
- Linguagem: TypeScript

## Navegação
- Ferramenta: Expo Router
- Estrutura: Navegação baseada em arquivos (file-based routing) com suporte a Bottom Tabs.

## Interface e Estilização (UI)
- Ferramenta: NativeWind
- Objetivo: Utilizar classes utilitárias do Tailwind CSS nativamente nos componentes.
- Ícones: @expo/vector-icons (integrado ao Expo).

## Formulários e Validação
- Ferramentas: React Hook Form + Zod
- Objetivo: Gerenciar a entrada de dados do usuário e validar regras de negócio de forma tipada, exibindo mensagens de erro.

## Gerenciamento de Estado
- Ferramenta: Zustand
- Objetivo: Gerenciar o estado global da aplicação na memória (ex: dados temporários, listas, tarefas).
